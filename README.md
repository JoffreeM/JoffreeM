# 👋 Hola, soy J-Mauricio! ![Visitas al perfil](https://komarev.com/ghpvc/?username=JoffreeM)

### Desarrollador Mobile & Multiplataforma | Especialista en Kotlin

Soy un desarrollador enfocado en el ecosistema Kotlin, apasionado por crear aplicaciones móviles y soluciones multiplataforma eficientes. Mi especialidad es el desarrollo con **Jetpack Compose** y **Compose Multiplatform** utilizando **Kotlin Multiplatform (KMP)**, aplicando el patrón arquitectónico **MVVM (Model-View-ViewModel)** para asegurar proyectos estructurados, escalables y fáciles de mantener. 

Mi experiencia abarca desde el diseño de apps nativas y multiplataforma, integración de servicios en la nube como **Firebase** y **Firestore**, hasta el desarrollo backend y la distribución oficial en la **Play Store**.
